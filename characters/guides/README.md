# Guides / Companions

This folder is a shared consumption/registration surface, not the GUIDE production workspace.

GUIDE Visual ID source locking, independent Cutout, Mask Spec, BODY/PROP/GEAR/reaction production and artistic QA remain owned by the existing GUIDE specialist pipeline.

TAKY-ASSETS may store:
- approved Visual ID/source authority pointers;
- approved runtime binaries delivered by the specialist owner;
- exact SHA/version/provenance for those approved outputs;
- app consumer pointers.

TAKY-ASSETS must NOT duplicate:
- GUIDE Cutout/Mask state machines;
- per-ID production gates;
- batch planning/audit ownership;
- artistic approval state.

Do not generate a character from a name alone.
Only specialist-owner-approved outputs may become shared runtime assets.
